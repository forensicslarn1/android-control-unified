# Alternative App Compatibility Notes

The alternatives view compares the Android version reported by the connected device against conservative current minimum requirements stored with each alternative. A green result means only that the reported Android major version meets the listed minimum; it is not a guarantee of hardware, regional, account, service, or vendor-feature compatibility. An amber result means the listed requirement exceeds the connected device’s Android version. Unknown requirements remain explicitly unverified and are not presented as compatible.

The current F-Droid listings confirm that NewPipe requires Android 6.0+, Jitsi Meet requires Android 8.0+, Fossify Messages requires Android 8.0+, and the latest AntennaPod listing requires Android 6.0+.[1] [2] [3] [4] The prior review recorded current requirements for Thunderbird, Organic Maps, Aves Libre, and Nextcloud.[5]
