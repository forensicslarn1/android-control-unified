Operational safeguards / 09

Safeguards make the workflow defensible

09

GATE / 01

Explicit device authorization

WebUSB selection and the Android RSA trust prompt must be completed before a shell command can run.

Owner-visible consent

GATE / 02

Visible command boundary

Operators see the selected operation and its exact command before the evidence queue begins.

No silent collection

GATE / 03

Receipt-backed outcome

Success, block, failure, and skipped status remain visible with command output and a timestamp.

Failure is retained

GATE / 04

Export under user control

Case bundles and migration shortlists download only after an explicit local export action.

No default upload

EXCLUDED

Not part of the standard browser workflow: root-only data extraction, permission bypasses, hidden collection, and secret dialer-code enumeration. Android or OEM denial is recorded as a valid outcome—not treated as an obstacle to defeat.
